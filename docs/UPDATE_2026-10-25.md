# 2026-10-25 源码同步

本次同步独立 SOLO 应用源码、必要运行资源和说明文档。中英文 README 同步更新，增加电脑协同、手机查看与操作、最新控制面板、完整依赖和运行边界。

## 应用变化

- `monitor/remote/`：HTTPS 身份与证书、设备权限、提醒目录和编辑、版本冲突检测、操作回执及共享来源执行网关。
- `monitor/phone/`：新版手机网页、长期设备管理、远程协同实况展示、提醒编辑与来源支持的授权入口。手机上的协同来源仍只读。
- `monitor/multi_diverse/`：绑定即协同、重启与断线恢复、地址更新、稳定的胶囊绘制、切换动画和统一背景的协同面板。
- `monitor/UI/`、`monitor/app.py`：品牌栏与控制面板布局、手机在线指示、声音总开关、协同提示音及在线设备常驻。
- `monitor/runtime_check.py`、`run.py`、`start.cmd`：当前解释器依赖诊断；Windows 可选按键绑定兼容与独立数据自检。
- `monitor/icon_asset/`：新的统一 LOGO 和运行所需多尺寸 ICO。源码启动不依赖打包目录。
