# Solo 个性化外观与悬挂卡通

本功能仅位于 `monitor_solo/`，不需要登录，不依赖主 BrightMoon。使用原来的启动入口，打开“个性化”。

## 控制面板颜色

“外观 → 控制面板颜色 → 选择面板颜色…”可选择任意 RGB 颜色；“恢复白色”恢复默认颜色。与应用背景壁纸合成时，继续使用原来的“面板透明度”。没有照片时面板颜色仍生效，面板外围保持纯白背景。

文字、选中状态、按钮、分隔线随面板的实际合成颜色调整。主要文字、次要文字和强调文字相对于面板平均底色达到至少 4.5:1 对比；复杂照片的局部明暗可能不同，用户仍可通过颜色和透明度改善可读性。文字与控件本身不会随面板透明度变淡。面板颜色与灵动岛颜色互相独立。

灵动岛外壳使用单层圆角表面，纯色和壁纸均直接到达同一个轮廓，轮廓外透明；不再叠画额外的深浅色边框。Logo 的状态环保留语义颜色与白色间隙，外围呼吸光晕采用连续径向渐变，并与实际壁纸像素混合，避免旧版三圈实线产生同心边框。所有任务的光晕统一画在图标与文字下方，切换任务时不会互相覆盖图标。壁纸详情卡也不再自动增加装饰描边。

## 悬挂卡通

1. 把带透明背景的 PNG 放入本项目 `data/rope/`；支持 `.png` 与 `.PNG`，不递归扫描子目录。
2. 打开“个性化 → 悬挂卡通”，开启“胶囊悬挂卡通”。首次开启自动选择第一张可读图片；已有选择时恢复原选择。
3. 上方提供挂件位置预览和横向滑条，默认居中；拖动时预览和实际挂件同步左右移动，按图片整体边缘保留左右至少 20px 的胶囊边距。位置按 0～100 保存，适配胶囊宽度及屏幕缩放。下方每页显示 6 张图片及名称，画框和选中边框均为 8px 圆角。名称来自文件名，不含扩展名。点击即可切换并保存。新增或替换文件后点击“刷新列表”，不需要修改代码。
4. 只有存在可见监控任务、且灵动岛处于胶囊形态时显示。没有任务时不会为了挂件额外弹出灵动岛。关闭挂件开关不影响任何 Agent 的监控开关。

PNG 自带的绳索直接使用，保留图片比例，裁去外部全透明空白，通常缩到 76 逻辑像素高、最多 80 逻辑像素宽。透明边缘使用 Windows 逐像素 Alpha 合成，避免透明色镂空造成紫边。胶囊形态下点击卡通角色可触发展开；完全透明的空白区域仍可穿透点击，窗口保持不抢夺输入焦点。

原图来源信息保留在 `data/rope/readme.txt`；本功能不改变原图，也不变更原资源的许可。

## 动画与生命周期

- 初次出现：灵动岛先完成圆点到胶囊的弹簧动画；稳定后等待 200ms，挂件在 200ms 内渐入。
- 从胶囊展开：点击胶囊或卡通角色使用同一个入口。已经出现的挂件先在 480ms 内完成两次“向下 4px → 回原位”，随后隐藏，再开始原有弹簧展开。整个过程通过 Tk 定时回调完成，不阻塞监控轮询或授权处理。按住角色后明显拖动或在透明空白处点击不会触发展开。
- 第二层进入第三层：挂件保持隐藏，直接执行原有展开动画。
- 回到胶囊：收起动画稳定后重新等待 200ms，再用 200ms 渐入。
- 快速连点只触发一次展开；点击不同任务圈时保留最近的明确选择。挂件还未出现、禁用或不可用时不额外等待拉绳动画。
- Escape、拖动、关闭挂件、切图、新任务批次、任务退场和退出应用会取消未完成的拉绳回调，避免之后突然展开旧任务。拖动结束后挂件在新位置重新渐入。
- 挂件最终透明度等于自身渐入 Alpha 乘以灵动岛不透明度。灵动岛完全透明时挂件也隐藏。
- 重启时先恢复图片选择，等胶囊已实际显示到桌面并完成开场动画后，才创建挂件窗口。首次显示与重新显示都核对窗口实际可见性，不能仅依赖 Tk 的 `normal` 状态；未显示时不向 Windows 提交透明图层，重新显示时清除旧绘制缓存。
- 创建或绘制遇到临时异常时释放该挂件窗口和位图，并自动重试，间隔从 250ms 逐步延长至最多 2 秒；成功显示后恢复正常。不会因为一次异常永久关闭挂件，也不会重放旧的点击/审批动作。没有任务、开关关闭或处于展开形态时仍不显示挂件。
- 接近屏幕底部时按剩余空间等比缩小；可用高度少于 24 逻辑像素时暂时隐藏，避免卡通跑到任务栏外。

## 保存与异常恢复

`data/settings.json` 使用 schema 4，包含 `panel_color`、`rope_enabled`、`rope_image`、`rope_position`（默认 50）；老配置自动补默认值，不改变既有壁纸、透明度和来源设置。挂件保存 `rope/<文件名>.png` 相对路径，连同 `data/` 移动后仍可使用。声音只在“个性化 → 声音”设置，外观页不再重复放声音控件。

设置使用临时文件加原子替换；写入失败不会改变当前有效配置。损坏、全透明、伪装格式、过大图片与指向目录外的链接不出现在候选列表。已经选中的文件丢失时隐藏挂件并提示，保留原来的选择；恢复文件后刷新即可重新使用。禁用也会保留选择。

## 代码边界

- `monitor/settings.py`：字段验证、旧配置兼容及原子保存。
- `monitor/src/rope_assets.py`：安全本地路径、动态 PNG 目录、读取与图像缓存。
- `monitor/UI/panel_palette.py`：根据合成底色计算文字与控件配色。
- `monitor/UI/island_surface.py`：单层纯色轮廓、连续渐变光晕、壁纸合成和小范围图像缓存。
- `monitor/UI/settings_panel.py`：个性化页签、颜色按钮、卡通开关与分页图片列表。
- `monitor/UI/rope_pendant.py`：纯动画时序和归属灵动岛的装饰窗口，管理淡入、拉绳、隐藏和释放。
- `monitor/UI/rope_surface.py`：Windows 原生逐像素 Alpha，预乘 BGRA、窗口句柄更新、位图与 DC 释放。不读取桌面像素。
- `monitor/UI/island.py`：胶囊开合、任务选择与挂件生命周期连接点；各来源详情、审批协议及数据适配器保持原有逻辑。
- `monitor/app.py`：设置交互、目录刷新和挂件图片注入。

### 重启挂件缺失修复

2026-10-16 复现：从磁盘恢复 `rope_enabled=true` 后，初始化几何尺寸时提前调用挂件同步，此时胶囊仍处于 withdrawn。挂件作为 transient 被提前创建并绘制，后续报告状态为 normal、Alpha 为 1，但 `winfo_ismapped()` 为 0，4 秒后仍未显示。旧用例在主窗口创建后才打开挂件开关，因此未覆盖此路径。另一个恢复缺口是创建/绘制失败后将 `unavailable` 永久置为 True。

修复集中在 `rope_pendant.py` 和 `rope_surface.py`：延后创建、核实映射、重新显示时使缓存失效、清理失败窗口并按有限频率重试。新增 `test_rope_startup.py` 通过独立 Python 进程运行真实 Tk 事件循环，不强行结束动画；覆盖持久化选择的连续两次启动、来源延迟连接、首帧原生绘制故障恢复、无任务不创建挂件。原生挂件用例还覆盖创建一半失败后的清理/重试、同一窗口隐藏后恢复及高频刷新不重置渐入时间。所有任务及数据来自临时测试目录，不操作真实 Agent。

本次最终完整回归：**202 passed，0 failed，0 skipped**，耗时约 25 秒；主项目 `monitor/` 的 2,274 个基线文件仍为 0 改动。修复前新增的持久化启动用例可稳定复现失败，修复后正常映射并显示，不需要用户再次切换卡通开关。
