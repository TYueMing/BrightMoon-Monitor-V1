# UI 设计与原型检查记录

日期：2026-10-20。对象为本目录静态原型；不代表 iOS/Android 真机或生产双向通信验收。

## 已执行检查

1. **JavaScript 语法**：`node --check Product/APP_design/app.js` 通过。
2. **浏览器装载**：实际打开 HTML/CSS/JS；图像已载入，无破损图像；页面控制台未观察到 error/warn。
3. **桌面几何**：上下宽度均为 420px；第二态正文约 182px；第三态约 518px；关闭动画后上下间隙约 12px（浏览器亚像素误差小于 0.1px）。
4. **三态行为**：第二态进入第三态；第三态切另一来源仍保留第三态；点击当前长胶囊可将完整详情收回第一态。
5. **窄屏布局**：浏览器 viewport 360、390、412px 下，页面与 APP 均无横向溢出；灵动岛头部与详情实际等宽。另检查 iOS、Android 平台框架与底部导航。
6. **审批确认**：先显示目标与作用范围；确认后先显示发送中，约 0.7 秒模拟来源接收，约 1.8 秒确认本次决定。文案明确 Agent 任务尚未完成。
7. **只读/失联**：两种场景的“同意本次”按钮均被禁用。
8. **不确定结果**：提交后立即切失联显示结果待核对；恢复连接仍保留未知状态；点击查询回执只确认已有结果，活动记录未添加第二次发送。
9. **配对向导**：输入演示邀请 → 核对数字 → 最小共享范围 → 新设备出现；不创建真实连接或凭据。
10. **提醒表单**：添加合成提醒“审查设计”，提交后出现在提醒列表，标题、时间、重复方式和来源设备正确显示。只保存在当前页面内存。
11. **外观**：切换雾蓝主题并打开减少动态效果，开关状态正确；原型遵守系统减少动画媒体查询。
12. **空闲场景**：无远程任务时仅保留一个本地胶囊，切回连体布局，显示下一条提醒。

## 检查中修正

- 手机预览不再将电脑 Codex 执行标成手机本机执行；本机区域用未来原生提醒示例，并标明规划。
- 操作提交/来源接收阶段不再提前显示“继续执行中”，不会使用完成绿色灯表示仍在执行的任务。
- 断线后恢复不会丢掉未知回执并重新开放同一授权按钮。
- 模拟延迟回调带场景代际，重置或切场景后旧回调不会污染新状态。
- 手机使用有界预览窗口与常驻底部导航，切换页面回到页面顶部。

## 设计复核

已经核对来源与任务所有者、两个权限方向、断线/恢复/撤销的不同含义、平台能力差异、静态资产更新和持久退场要求。完整约束在 `APP_UI_design.md`，原型只用于演示核心页面与流程。

未验收部分：真实配对加密、跨设备请求竞争、后台/锁屏通知、网络重连时序、来源适配器实际执行、原生悬浮窗、手机硬件、大字体和完整无障碍。它们需要后续实施与真机测试，不属于本次页面原型完成的能力。

原型中的固定统计、固定时间、有限提醒字段和短期定时回执是演示，不应直接作为生产状态管理。页面原型有重绘简化；正式授权组件必须保持稳定节点与草稿。部分小型文本按钮的热区与字体也需按文档中的平台标准完善。
