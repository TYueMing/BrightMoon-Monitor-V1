# 2026-10-30 源码同步

同步独立 SOLO 的桌面源码、静态资源、ESP32 固件和文档。仓库根目录对应开发目录 `monitor_solo/`，不包含 BrightMoon 主程序。

## 更新内容

- ESP32-S3-Touch-LCD-3.49 固件、胶囊多任务/多设备 UI、审批阅读与回执、待办知晓/暂缓、电源交互。
- 远程连接页增加 ESP32 设置；USB 扫描网络、配网、验证后 NVS 保存，Wi-Fi HTTPS 同步、地址发现和自动重连。
- USB/Wi-Fi 共用 ControlBroker、OwnerBridge 和命令日志，防止重复执行；支持板卡凭据撤销和错误配置回退。
- 修复 Tk 原生下拉菜单 `popdown` 焦点查询异常；更新设备设置、来源操作路由和 pyserial 运行依赖。
- 中文/英文 README 增加 ESP32 入口，发布文档引用的静态示例预览。

## 验证与边界

实现阶段完整 SOLO 回归 433 项通过；最终 ESP32 专项非 UI 32 项通过，两项 Tk 界面测试在独立进程分别通过。当前 Conda 环境连续创建第二个 Tk 窗口出现 Tcl 资源读取异常，因此采用独立进程复测，并未把失败计作通过。

最终 ESP32 固件编译通过：程序 2,400,812 字节（76%），静态 RAM 188,532 字节（57%）。无线状态、认证、撤销与控制去重通过回环 HTTPS 测试；真实板卡射频、路由器、防火墙、NVS 断电与 USB 拔插仍需实机验收。

无线实现与安全边界见 [WIRELESS.md](../monitor/esp32/WIRELESS.md)。SD 卡通/媒体上传尚未实现。此次不烧录或重新打包。

发布副本另通过运行依赖检查和原生自检，覆盖资源/持久化、隔离数据、托盘关闭、实例唤回、自启注册清理与正常退出。已核对发布源码与本地选定源码一致，新增文档链接有效，暂存区没有本次排除的测试、打包或私有数据文件。
