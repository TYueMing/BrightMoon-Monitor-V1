# 空闲角色与提醒任务图标

## 使用

打开「个性化 → 空闲角色」。开关默认开启，与胶囊下方的「悬挂卡通」独立。关闭后，空闲第二、第三态均不显示角色；已选图片仍保留，重新开启即可恢复。

开发版素材目录为 `monitor_solo/data/cartoon/`，其中已有月光星尘、Jay 等图片。目录扫描支持 PNG、WebP，界面每页展示六张缩略图及名称。进入该页或点击「刷新目录」时重新扫描，点击图片立即切换，自动保存。首次没有选择时选中按名称排序后的第一张有效图片，不把任何角色写死在绘制代码里。已选择但被删除、损坏的文件不会被别的角色悄悄替换；会提示重新选择，恢复文件后刷新即可继续显示。

「上传自定义…」打开系统文件选择框。请上传**已抠图、具有透明背景**的 PNG / WebP。程序会验证尺寸、格式、透明度，拒绝不透明、完全透明、损坏以及超过 40 MB / 1600 万像素的文件；程序不负责自动抠图。导入会去掉透明空白边距并生成本地 PNG 副本，原文件不修改；文件名包含内容摘要避免同名覆盖。大图副本限制在 768×768 内，保留比例。

## 显示规则

- 胶囊第一态：角色不显示；原有顶部 Logo、指示灯、标题和文字保留。
- 无可见监控任务，且未来 1 小时没有提醒：第二态即可在右下角显示角色。
- 无可见监控任务，但未来 1 小时有提醒预告：第二态保留完整预告；第三态右下角显示角色。
- 第三态沿用当前选择，默认高度为两态高度差减 8px，即 80 逻辑像素。为避免极宽自定义图片遮挡文字，宽度上限为 120px，等比缩放；适配 DPI。
- 真实 Agent 或正在提醒的待办出现时，使用各自的监控界面，不显示空闲角色。该设置不会开启常驻、修改提醒时间或干扰审批。

右下角留出右侧 26px、底部 10px 的安全距离。第二态的空闲标语为角色预留空间，第三态重复规则与标语排在左侧。

单条待办的胶囊态已移除单独的 20px Logo 绘制分支，改用统一的 `_draw_ring()`：三个形态顶部均为 28px Logo、外圈指示灯及聚焦呼吸光晕。正文内小 Logo 不属于顶部任务指示器。

## 数据、代码与安装版

- `monitor/src/cartoon_assets.py`：安全相对路径、目录扫描、透明图校验、导入与文件更新时间缓存。
- `monitor/settings.py`：持久化 `cartoon_enabled` 和 `cartoon_image`，后者为 `cartoon/文件名.png` 或 WebP 相对路径；迁移旧设置无需修改数据结构。
- `monitor/app.py`：选择、开关、上传和刷新；把已解析图片提供给 UI。
- `monitor/UI/cartoon_panel.py`：独立的个性化角色选择页。
- `monitor/UI/resident.py`：空闲卡片显示规则、布局与 DPI 缓存。动画每帧不读取磁盘。
- `monitor/UI/task_strip.py`：单条待办复用标准指示灯。

安装版素材保存在用户可写的 `%LOCALAPPDATA%/MonitorSolo/data/cartoon/`。打包只携带 `packaging/assets/cartoon/月光星尘.png` 这个明确的默认素材，首次运行复制到用户数据目录，已存在同名文件不覆盖；不会把开发者 `data/cartoon/` 里的上传图片打进安装包。本次未实际打包。
