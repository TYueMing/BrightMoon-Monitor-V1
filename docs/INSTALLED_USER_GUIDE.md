# Monitor Solo 安装版使用说明

安装后通过桌面的 Bright Moon Monitor (Solo) 图标或开始菜单启动。图标来自 MonitorSolo_logo.png。无需另装 Python、Conda、pip、Node.js 或浏览器运行环境，也不需要 BrightMoon 登录账户。

首次打开时 Agent 监控来源关闭，本地“任务提醒”默认开启。请先在本机安装并运行你需要使用的 Codex、OpenCode 或 DeepSeek Harness，再在监控面板开启对应来源；数据位置不标准时在来源设置中指定。Solo 本身不安装、不启动 Agent，不提供它们的账户或 API。

监控页顶部的“灵动岛常驻”默认关闭，可开启并自动保存。无任务时显示绿色呼吸灯、MonitorSolo Logo、大号斜体 Bright Moon 和循环滚动的“无任务！”，滑入与滑出各 2 秒，完整文字停留 1 秒。展开后可看最近的下一条提醒及实际提醒时间，再展开在右下角显示所选空闲角色；未来 1 小时没有提醒时第二态即可显示。任务完成并超过保留时间后照常退场，最后一条退场时自动收回空闲胶囊；常驻不延长任务保留时间、不代替 Agent 或任务提醒的开关。

读取会话日志只能显示进展。审批和回答需要来源应用提供实时连接；按钮是否可用以实际连接能力为准，Solo 不会绕过来源应用的权限检查。CodeAgent 仍是占位。

DeepSeek Harness 的日志监控不需要桥接。需要审批交互时，完全退出 Harness 后，按开发者的打包说明运行安装目录 `_internal/monitor/deepseek_monitor/install_bridge.ps1`，指定自己的 Harness 安装目录。该桥使用 Harness 自带的 Node/Electron，无需单独安装 Node。当前桥适配 Harness 0.2.0-rc.2，其他版本可能需要适配。正常启动不会自动修改 Harness 的插件配置。

左侧“任务”可以添加本地待办，选择单次、周一至周日重复或每隔 N 小时（整数 1～8760，和星期互斥），输入提前提醒 2～10 分钟。按小时重复以首次日期时间为起点。预定时间前 N 分钟显示灵动岛，到预定时间收起；“忽略”延后 5 分钟再提醒，“已知晓”只结束本次。最小形态显示左侧 Logo 和居中的最多 5 字标题，两次展开可看到内容和重复详情。待办优先于 Agent 排列，最多同时显示 5 圈。“新增任务”右侧图标可切换列表/网格，自动保存。

“监控 → 任务提醒”可关闭所有待办卡片与提示音，但保留任务、重复计划和已知晓记录；重新开启只恢复仍在有效窗口内的提醒。在“个性化 → 悬挂卡通”可以拖动横向位置滑条，预览和实际图像同时移动，默认居中，左右各保留至少 20px 边距并自动保存。

侧栏底部的“个性化 → 声音”可独立选择待办提示音，每轮提醒播放 3 遍；Agent 完成音仍为 1 遍。Solo 需要保持运行；从托盘退出程序或电脑睡眠期间不会提醒；重新打开只恢复仍在有效窗口内的提醒，不补发已错过的历史提醒。

设置、历史壁纸、任务显示去重记录、本地待办和悬挂卡通保存在：

`%LOCALAPPDATA%\MonitorSolo\data`

可在资源管理器地址栏粘贴此路径。放入 `rope` 文件夹的 PNG 可在个性化页面刷新选择。安装文件与个人数据分开；升级保留个性化设置，卸载默认也保留这些数据。重新安装后继续使用原配置。此数据目录只服务当前 Windows 用户，不与其他用户共享。

`tasks.sqlite3` 保存待办标题、内容、重复计划、已知晓及延后提醒记录；`settings.json` 保存提示音选择。备份时先退出 Solo，再复制数据目录，恢复时同样保持程序关闭。

点击主窗口 × 会隐藏到系统托盘，监控继续；右键托盘选择「退出」才会结束 Solo 和灵动岛。再次启动不重播已记录的结束任务。没有任务时默认隐藏灵动岛，开启常驻则保留空闲胶囊。

如果准备卸载且曾安装 DeepSeek 交互桥，应先退出 Harness，使用同一脚本加 `-Uninstall` 移除桥接，然后卸载 Solo，避免 Harness 保留失效的插件链接。卸载 Solo 不会删除 Agent 程序、会话或账户。

源码版的 `data` 不会自动迁移到安装版。如需迁移自己的数据，应关闭两者后自行备份并复制该目录内容到上述位置；不要把自己的个人 data 交给其他用户。

在「个性化 → 空闲角色」可关闭角色，或从本地目录的缩略图列表中选择。支持上传自定义 PNG / WebP：请先抠图并保留透明背景。安装版自动保存到用户数据目录的 `cartoon/`，切换与开关会记住；与胶囊下方的悬挂卡通独立。目录中新加的图片可用「刷新目录」加载。

空闲预告按未来 1 小时内的实际开始提醒时间统计：顶部显示「N项任务」，数字深红色、文字深蓝色，不带背景框，第二态展示最近一条详情，其余以「另有 N 项」显示；没有符合条件的提醒时才显示「无任务！」。


## 启动、后台运行和卸载

解压发布 ZIP 后运行 `MonitorSolo-0.1.0-windows-x64-setup.exe`。按安装向导完成安装，默认创建桌面快捷方式；日常通过桌面或开始菜单启动。无需使用终端或安装 Python。目标为 Windows 10（1809 或更新）/ Windows 11 x64。

「个性化 → 通用」提供开机自启开关。默认关闭；开启后在当前用户登录 Windows 时进入后台，不弹出控制面板。状态来自 Windows 当前用户启动项，关闭开关会实际移除该启动项。灵动岛按常驻开关及任务状态显示，自启不会自动开启 Agent 来源。

点击窗口右上角 × 只隐藏控制面板，监控和提醒继续。右下角系统托盘中会保留 MonitorSolo 图标（可能位于折叠的小箭头内）；双击图标或再次点击桌面快捷方式可打开面板。右键托盘图标选择「退出」，或者在「个性化 → 通用」点击「退出监控器」，才会结束程序和灵动岛。托盘暂时不可用时，× 会退回普通任务栏最小化，防止窗口无法找回。

在 Windows 设置的「已安装的应用」中卸载，或使用开始菜单的卸载入口。卸载会先关闭 Solo，并移除快捷方式和自启项；交互卸载时会询问是否删除个人数据，默认选择「否」保留任务、设置和图片。静默卸载始终保留数据。升级安装保留个人数据和自启选择。

安装程序暂未使用商业代码签名证书签名；Windows 可能提示未知发布者。分发包提供 SHA256 校验文件。
